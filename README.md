# alu-back-end

Python scripts that gather data from the JSONPlaceholder REST API
(https://jsonplaceholder.typicode.com) and export employee TODO lists.

## Requirements
- Python 3
- requests module (`sudo apt install -y python3-requests`)

## Files (in `api/`)
| File | Description |
|------|-------------|
| 0-gather_data_from_an_API.py | Prints an employee's TODO progress for a given ID |
| 1-export_to_CSV.py | Exports an employee's tasks to USER_ID.csv |
| 2-export_to_JSON.py | Exports an employee's tasks to USER_ID.json |
| 3-dictionary_of_list_of_dictionaries.py | Exports all employees' tasks to todo_all_employees.json |
